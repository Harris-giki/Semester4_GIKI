# 📚 GIKI CS 4th Semester Resources Repository

Welcome to the **GIKI CS 4th Semester Resources** repository!
This repository contains a curated collection of academic materials used by Computer Science students during their 4th semester at **Ghulam Ishaq Khan Institute of Engineering Sciences and Technology (GIKI)**.

## 🧠 What's Inside?

This repository includes:

* 📘 **Books & Textbooks**
* 📝 **Handwritten and Typed Notes**
* ✅ **Evaluation Materials** – Quizzes, Assignments, and Practice Tests
* 📂 **Additional Resources** – Slides, Reference Papers, and Summaries

All resources are organized by course for easy navigation and quick access.
